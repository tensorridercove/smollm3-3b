# SmolLM3-3B

### Hugging Face's efficient 3B parameter language model

SmolLM3-3B is Hugging Face's latest small language model, achieving remarkable capabilities in a 3B parameter package. Ideal for deployment on mobile, embedded, and resource-constrained hardware.

<br>

---

## Features

| | |
|:---|:---|
| **3B Parameters** | Surprisingly capable reasoning and instruction-following at tiny scale |
| **On-Device Ready** | Optimized for inference on mobile and edge devices |
| **Apache 2.0** | Fully open — fine-tune, deploy, and build products without restrictions |
| **Long Context** | Supports extended context windows for document understanding tasks |
